# BookMyPG
A web app to help users find and book PG accommodations easily. Browse listings, compare prices, and manage bookings all in one place.
Book My PG is a full-stack web application designed to help users find and book paying guest accommodations with ease. It features a searchable database of PG listings, real-time booking functionality, user reviews, and a dashboard for property owners to manage their listings. Built with modern web technologies, the app aims to streamline the PG discovery and reservation process for students and professionals.
